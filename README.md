# Todo List

A simple personal todo tracker for organizing daily tasks, weekly goals, and future backlog items.

## Files

- [todo.md](todo.md) - The main checklist for tasks and progress tracking

## How to use

1. Open [todo.md](todo.md).
2. Add your tasks under the relevant section.
3. Mark completed items with `[x]`.
4. Keep the backlog updated as new tasks appear.

## Suggested structure

- Today: immediate priorities
- This Week: short-term goals
- Backlog: ideas or future tasks
- Completed: finished items

## Notes

This repository is intentionally lightweight and easy to maintain. You can expand it by adding more checklist sections or converting it into a project-specific tracker later.
